# AK Net - صفحات بوابة الدخول (HotSpot Captive Portal)
> مصممة خصيصاً لشبكات الميكروتك (MikroTik RouterOS 7 & 6) مع توافق كامل لنظام إدارة المستخدمين (User Manager v7).

---

## 🌟 مميزات المشروع

- **تصميم عصري ومتجاوب (Responsive UI):** واجهة مستخدم حديثة وأنيقة تدعم جميع الهواتف الذكية، الأجهزة اللوحية، والشاشات المكتبية مع دعم كامل للغة العربية (RTL).
- **توافق تام مع MikroTik RouterOS 7:** دعم دقيق لمعمارية متغيرات ومعالجة بيانات RouterOS v7 و User Manager v7 عبر استعلامات الـ RADIUS المباشرة.
- **عرض الرصيد والوقت المتبقي بدقة:** احتساب ذكي للرصيد المتبقي (بالجيجابايت/الميجابايت) والوقت المتبقي دون الوقوع في خطأ إظهار "غير محدود" عند فراغ المتغيرات.
- **عدادات حية (Live Timers):** عداد ثواني مباشر لوقت الاتصال والعد التنازلي لصلاحية الجلسة، مع شريط تقدم (Progress Bar) تفاعلي لحجم استهلاك البيانات.
- **حماية من الهجمات التخمينية (Brute-Force Lockout):** قفل تلقائي مؤقت للجلسة بعد تجاوز عدد محاولات الدخول الخاطئة عبر التخزين المحلي (`localStorage`).
- **لوحة معلومات منبثقة للجلسة:** عرض تفاصيل عنوان IP، عنوان MAC، سرعة الاستهلاك، اسم الفئة، ورابط مباشر لبوابة User Manager الرسمية مع مسار الـ slash `/` المصحح لتفادي خطأ 404.
- **دعم آليتي المصادقة (CHAP & PAP):** توافق ديناميكي مع تشفير MD5 لكلمات المرور أو الدخول المباشر.

## 🚀 طريقة التثبيت على راوتر MikroTik

### 1. رفع الملفات إلى الراوتر
1. افتح برنامج **WinBox** واتصل بالراوتر.
2. توجه إلى قائمة **Files**.
3. قم بإنشاء مجلد باسم `hotspot` (أو داخل مجلد التخزين المناسب مثل `flash/hotspot`).
4. اسحب كافة ملفات هذا المستودع وضعها داخل المجلد.

### 2. إعداد ملف تعريف الخادم (HotSpot Server Profile)
من خلال **Terminal** في الراوتر، قم بتنفيذ الأمر التالي:

```routeros
/ip hotspot profile
set [find default=yes] \
    html-directory=hotspot \
    login-by=cookie,http-chap,http-pap \
    use-radius=yes \
    radius-interim-update=30s
```

### 3. إعداد سمات اليوزر مانجر (User Manager v7)
لضمان تزويد الصفحة بحدود الرصيد والوقت بدقة لكل باقة عبر RADIUS:

```routeros
/user-manager/user/group
# مثال لباقة 200 ريال:
set [find name="200RY"] attributes="Mikrotik-Total-Limit=838860800,Session-Timeout=86400"
# مثال لباقة 500 ريال:
set [find name="500RY"] attributes="Mikrotik-Total-Limit=2147483648,Session-Timeout=259200"
# مثال لباقة 1000 ريال:
set [find name="1000RY"] attributes="Mikrotik-Total-Limit=5368709120,Session-Timeout=604800"
```
